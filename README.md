# 泉城智行 · 室内定位导航小程序 Demo

基于《泉城智行_室内定位导航小程序_PRD》（V1.2）实现的可交互前端 Demo，以手机壳形式模拟微信小程序的运行效果。

## 运行

```bash
npm install
npm run dev        # 开发预览
npm run build      # 生产构建 → dist/
```

## 演示操作指南

- **点击地图任意位置** = 模拟定位行走
- 搜索框输入 `wsj`、`wc`、`厕所`、`12A` 均可命中
- 导航页「模拟偏航」按钮可演示自动重新规划
- 走到餐饮区附近会自动触发地理围栏广告
- 「我的 → 演示工具」可触发应急疏散模式、重置数据

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS，纯前端模拟（定位、路径规划均在本地完成，无后端依赖）。
